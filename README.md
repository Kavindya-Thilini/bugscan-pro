# BugScan Pro — Automated QA Bug Scanner

A full-stack QA tool that scans any website for bugs including broken links, missing alt text, console errors, and broken images. Features both automated scanning and manual bug reporting with persistent storage.

## Features
- Automated scanning with Puppeteer headless browser
- Broken link detection (404, 500 errors)
- Broken image detection
- Missing alt text detection (accessibility)
- JavaScript console error capture
- Manual bug reporting
- Persistent scan history
- Dashboard with severity stats

## Tech Stack
- **Backend:** Node.js, Express, Puppeteer
- **Frontend:** HTML, CSS, JavaScript (vanilla)
- **Storage:** JSON file-based
